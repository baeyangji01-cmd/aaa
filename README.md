# 안!부! — 안전한 부동산

> 당신의 안전한 부동산을 위해 당신의 안!부!를 묻습니다.

군 AI 교육 해커톤 출품작. 군인(장기복무 간부 · 초급간부 · 전역 장병)이 복무기간 · 무주택 기간 · 근무지를 기준으로
지원 가능한 청약 유형과 주변 분양 일정을 찾고, 전월세 계약 전 위험 신호를 점검하도록 돕는 웹사이트입니다.

## 내 컴퓨터에서 보기

`index.html`을 더블클릭하면 브라우저에서 열립니다. 지도 · 글꼴을 불러오기 위해 인터넷 연결이 필요해요.

## 주요 기능

| 모듈 | 내용 |
|---|---|
| 군 주거 지원 | 관사 · 전세자금 지원 · 주택수당 비교, 급지별 전세 한도(1급지 3.5억 · 2급지 2.9억 · 3급지 2억), 주택수당 월세 예산으로 매물 검색, 반전세 월세 지원 계산 |
| 가족 · 교육 | 지역 맘카페 · 군인가족 카페 검색 연결, 군인 자녀 고교 · 대입 특별전형 검색, 주소로 읍 · 면 판정 · 농어촌 전형 자격 진단 |
| 군인 청약 내비 | 기준 위치 + 반경 안의 분양 일정, 지원 가능 공급 유형 표시 (지도 · 목록) |
| 자격 진단 | 일반 1순위, 군인 기관추천(10년+), 수도권 기타지역 자격(10년+), 해당지역 간주(25년+), 제대군인, 신혼부부, 생애최초, 다자녀 |
| 청약 가점 | 무주택 기간(32) + 부양가족(35) + 통장 가입기간(17) = 84점 |
| 지역 탐색 | 시군구 검색 · 접경지역 레이어 · 네이버/구글 지도 · 실거래가 연결 |
| 안부 체크리스트 | 전월세 계약 전 14개 항목, 깡통전세 계산기 |

## 폴더 구조

```
anbu-site/
├─ index.html             페이지 본문
├─ css/style.css          디자인 (관제 콘솔 스타일)
├─ js/config.js           API 키 · 급지별 전세 상한 · 주택수당 금액 설정
├─ js/sample-sites.js     예시 분양 데이터 · 기준 위치 목록
├─ js/mil.js              지도 · 청약 내비 · 자격 진단 · 가점
├─ js/support.js          군 주거 지원 · 급지 한도 · 주택수당 월세 검색
├─ js/family.js           지역 커뮤니티 · 군인 자녀 특별전형
├─ js/app.js              체크리스트 · 계산기 · 위협 유형 · 가이드
└─ data/korea-topo.js     시군구 경계 (통계청 2013)
```

## 실데이터 연결 (선택)

1. 공공데이터포털에서 "한국부동산원_청약홈 분양정보 조회 서비스" 활용 신청 → 인증키 발급
2. `js/config.js`의 `applyhomeServiceKey`에 키 입력 → 새로고침하면 "청약홈 실데이터"로 바뀌어요
   - 응답 필드명과 주소는 공공데이터포털 명세로 한 번 확인하세요. 실패하면 자동으로 예시 데이터를 보여줘요.
   - 실데이터는 좌표가 없어서 주소의 시군구 중심점으로 위치를 잡아요.

## 배포 계획 (아직 연동 안 함)

1. **GitHub**: 이 폴더를 저장소로 올리기 (`git init` → `git add .` → `git commit` → `git push`)
2. **Vercel**: Add New Project → 저장소 선택 → Framework Preset `Other` → Deploy
3. **Supabase**
   - Edge Function으로 청약홈 API를 대신 호출 (키를 브라우저에 노출하지 않기) → `config.js`의 `proxyUrl`에 함수 주소
   - 로그인 사용자별 프로필 · 관심 지역 저장 (지금은 브라우저 localStorage: `anbu-profile`, `anbu-checks`)

## 주의

- 분양 일정과 전월세 매물은 **시연용 예시 데이터**입니다 (실제 단지 · 매물 아님).
- 급지별 전세 상한(3.5억/2.9억/2억)과 주택수당(월 16~20만 원), 급지 구분은 `js/config.js`의 `housing`에서 고칠 수 있어요. 최신 기준은 국군복지단 · 부대 인사과에서 확인하세요.
- 군인 자녀 전형은 확인된 예시(한민고, 한양대, 대전대 등)이고 해마다 바뀝니다. 맘카페는 네이버 카페 검색 결과로 연결합니다.
- 자격 진단은 단순화한 안내용 규칙입니다. 최종 자격은 입주자모집공고와 청약홈에서 확인해야 합니다.
- 군부대 · 관사 위치는 군사보안상 표시하지 않습니다. 기준 위치는 동네 중심점만 씁니다.
- 지도: Leaflet, © OpenStreetMap contributors © CARTO. 경계: southkorea/southkorea-maps.

## AI 안부 (Claude API)

- 등기부등본 해석 · 특약 점검 · AI 상담은 Vercel 서버 함수 `api/ai.js`가 Claude API를 불러서 동작해요.
- Vercel 프로젝트 → Settings → Environment Variables에 `ANTHROPIC_API_KEY`를 등록하고 다시 배포하세요. 키는 코드나 저장소에 넣지 않아요.
- 키가 없으면 화면에 `예시 모드`가 표시되고, 예시 서류의 분석 결과만 보여줘요.
